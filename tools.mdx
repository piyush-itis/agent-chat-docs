---
title: Magica tools
---

These routes **queue** Crop Image, GPT Image 2, and Merge Videos on the server. They never expose operator Magica keys. Work still runs on Trigger (`agent.turn` + `magica.run`).

`POST /v1/tools/{crop_image|gpt_image_2|merge_videos}` returns **202** with `{ chatId, messageId, runId, realtime }`. Poll `GET /v1/runs/:runId`. Generated files appear on `generatedAssets`.

A second active run on the same chat returns `409 ACTIVE_RUN`. Missing `chatId` creates a new chat titled `{toolName} run`.

Credits use the same ledger as the chat app. New grant is **10,000,000** micro-units. Insufficient balance returns `402 INSUFFICIENT_CREDITS`. Tool estimates use a ~200k unit floor so a nearly empty wallet fails before Magica starts.

## Crop

`POST /v1/tools/crop_image`

```json
{
  "chatId": "optional",
  "input": {
    "image_url": "https://...",
    "crop": { "x": 0, "y": 0, "width": 50, "height": 50 },
    "unit": "percent"
  }
}
```

`unit` is `percent` or `pixel`. You can send flat `x`, `y`, `width`, `height` instead of `crop`, but not both.

## Generate or edit

`POST /v1/tools/gpt_image_2`

```json
{
  "input": {
    "mode": "text",
    "prompt": "a red bicycle"
  }
}
```

`mode: "edit"` also requires `image_url`.

## Merge videos

`POST /v1/tools/merge_videos`

```json
{
  "input": {
    "video_urls": ["https://.../a.mp4", "https://.../b.mp4"],
    "transition": "none"
  }
}
```

`video_urls`: 2–100 items. `transition`: `none` | `fade` | `dissolve`.

## Where media lives

Magica returns a provider `url`. Postgres stores that on `GeneratedAsset`. If S3 is configured on the backend and Trigger worker, a copy is written to `durableUrl`. Today, without S3, files stay on Magica (and Transloadit for user uploads).
